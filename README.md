# 🎯 Learning Sprint Planner

> A clean, responsive, single-page web application designed to help learners plan one-week learning sprints, set clear goals, track actionable tasks, and visualize their progress in real-time.

## ✨ Features

- **Step 1: Choose a Focus:** Set a clear target for what you want to learn during the week.
- **Step 2: Define Weekly Goals:** Outline actionable goals with auto-saving text fields.
- **Step 3: Task Management:** Add, complete, and delete tasks dynamically with instantaneous visual feedback.
- **📊 Dynamic Progress Visualizer:** Interactive SVG ring indicator calculating completion percentage in real time.
- **♿ Accessible Design:** Built using semantic HTML elements, `aria` attributes, live regions, and screen-reader accessibility labels (`.sr-only`).
- **🔤 Clean Typography:** Powered by *DM Sans* and *Fraunces* Google Fonts.

---

## 🛠️ Built With

- **HTML5:** Semantic markup & standard SVG elements.
- **CSS3:** Custom layout system using Grid & Flexbox (`style.css`).
- **JavaScript (ES6+):** Dynamic DOM manipulation & event handling (`app.js`).
